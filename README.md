# Campus Bridge: AI-Driven Event Networking Platform[cite: 1]

Campus Bridge is a progressive web application (PWA) designed for college campuses to streamline event creation and connect students, alumni, and faculty in a live chat ecosystem. By utilizing fine-tuned LLMs and encrypted algorithms, it provides an intuitive, frictionless digital campus experience that prevents proxy attendance, reduces organizer workload, and bridges communication gaps.

---

## 🚀 Core Features & Modules

*   **Auth & RBAC Module:** Manages user registration, JWT login, and role-based route protection.
*   **Event Manager Module:** Handles CRUD operations for events and the Admin approval workflow.
*   **AI Service Module:** Interfaces with external LLM APIs (Gemini API and Hugging Face) to instantly draft event descriptions and generate posters based on prompts.
*   **Ticketing & QR Module:** Generates secure, personalized encrypted QR strings binding Student IDs to Event IDs to eliminate proxy check-ins.
*   **Scanner App Module:** Decodes QR codes via webcam to update attendance in real-time.
*   **Digital Notice Board:** Serves as a centralized hub for official administration announcements, allowing for department filtering and pinning priority notices.
*   **Anonymous Complaints:** A secure reporting system with image attachment support and strict anti-abuse policies where offensive talk reveals the user's identity.
*   **Campus Connect:** A live campus ecosystem for networking among students and alumni.

---

## 💻 System Requirements

### Software
*   **Operating System:** Platform independent (Progressive Web App).
*   **Frontend:** React.js for responsive UI development.
*   **Backend:** Node.js Express.js for real-time architecture, push notifications, and REST API creation.
*   **Database:** Firebase for user profiles, event data, and real-time chat, alongside PostgreSQL.
*   **Media Management:** Cloudinary for hosting and optimizing AI-generated event posters.
*   **AI Services:** Gemini API / Hugging Face for friction-free text generation.

### Hardware
*   **Client Device:** System with Webcam/Camera for Live QR Video Capture.
*   **Server:** Node.js, Express, and Database hosting capable system (GPU accelerated using RTX 4050).
